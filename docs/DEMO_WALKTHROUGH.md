# Demo walkthrough — PNC Nexus (10 menit)

**Tujuan:** tunjukkan nilai MVP ke principal tanpa overclaim.

## Setup
- Jalankan app + seed
- Siapkan 3 browser/profile: Admin · Operator · Mitra terverifikasi

## Script

| Menit | Aktor | Aksi | Pesan kunci |
|-------|-------|------|-------------|
| 0–1 | — | Landing | “Daftar sekali. Tersalurkan. Berkembang.” Satu pintu, tiga jalur tipis. |
| 1–3 | Admin | Login → approve 1 mitra menunggu | Kurasi manual = kualitas jaringan |
| 3–5 | Mitra | Kerja: lihat peluang → apply | Hanya mitra terverifikasi yang apply |
| 5–6 | Mitra | Komoditi: buat listing / tertarik | “Penawaran mitra”, harga indikatif |
| 6–8 | Mitra | Pemerintahan: baca disclaimer → minta dampingan | Bukan LPSE; tidak jamin tender; INAPROC eksternal |
| 8–9 | Operator | Pipeline: pindah kartu | Penyaluran manusiawi, bukan AI magic |
| 9–10 | Admin | KPI + export CSV | Operasional siap pantau |

## Yang sengaja tidak di-demo
Payment, chat, submit tender, fee pencari kerja, klaim harga pemerintah.
