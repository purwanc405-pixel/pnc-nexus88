# Brand Voice — PNC Nexus

**Bahasa:** Indonesia  
**Audience:** mitra kontraktor/UMKM, operator internal, admin  
**Prinsip utama:** profesional hangat · transparan · anti-klaim berlebihan  
**Compliance copy:** selaras Research 8 Sep 2026 (`briefs/pnc-nexus-compliance-brief-2026-09-08.md`) — bukan legal opinion.

---

## 1. Karakter suara

| Dimensi | Ya | Tidak |
|---------|----|-------|
| Nada | Hangat, jelas, menghormati waktu pembaca | Kaku birokratis, atau terlalu “salesy” |
| Klaim | Spesifik, dapat diverifikasi (“tim meninjau dalam 1–3 hari kerja”) | Absolut (“pasti menang”, “dijamin kerja”, “harga pemerintah”) |
| Transparansi | Sebut batasan platform di muka | Sembunyikan risiko / seolah afiliasi pemerintah atau lembaga penempatan |
| Aksi | Imperatif singkat (“Kirim minat”, “Lengkapi profil”) | Frasa panjang berbunga |
| Empati | Akui menunggu verifikasi tanpa menyalahkan user | Menyalahkan mitra atau pejabat |

**Kalimat panduan:**  
> Kami bantu Anda masuk jaringan, memahami peluang, dan tersalurkan — tanpa berjanji hasil yang di luar kendali kami.

---

## 2. Persona copy per peran

| Peran | Tone tambahan |
|-------|----------------|
| Mitra baru | Ramah, pandu langkah demi langkah, jelaskan “mengapa menunggu verifikasi” |
| Mitra terverifikasi | Langsung ke aksi; hormati bahwa mereka sudah lolos kurasi |
| Operator | Ringkas, operasional, status jelas |
| Admin | Netral, audit-friendly, tanpa humor berlebihan di aksi kritis (tolak/tangguhkan) |

---

## 3. Kata & frasa yang **disarankan**

- jaringan mitra · penyaluran · peluang · minat · dampingan internal  
- menunggu verifikasi · terverifikasi · ditinjau · dihubungi · tersalurkan  
- **papan lowongan mitra** · perekrutan oleh pemberi kerja / mitra  
- **penawaran mitra** · harga indikatif (bukan harga resmi pemerintah)  
- informasi indikatif · bukan jaminan · verifikasi ke sumber resmi · **Buka di INAPROC**  
- daftar sekali · tersalurkan · berkembang

## 4. Kata & frasa **terlarang**

### 4.1 Umum / pemerintahan (tetap berlaku)

| Terlarang | Alasan | Ganti dengan |
|-----------|--------|--------------|
| portal resmi (pemerintah / LPSE / SPSE) sebagai klaim Nexus | Menyesatkan afiliasi | platform jaringan mitra independen |
| tender pasti / dijamin menang / lolos pasti | Klaim tidak etis & berisiko | tidak ada jaminan hasil pengadaan |
| daftar di LPSE lewat kami / submit tender di sini / pengganti SPSE | Out of scope + menyesatkan | minta dampingan (internal) · Buka di INAPROC |
| login SPSE / upload dokumen tender di Nexus | Menyerupai situs palsu | deep-link eksternal ke INAPROC saja |
| afiliasi kementerian / BUMN resmi (tanpa bukti) | Klaim palsu | peluang terkait pemerintahan (info jaringan) |
| escrow / bayar di platform (MVP) | Fitur belum ada | (jangan sebut) |
| AI matching otomatis / ML (MVP) | Belum ada | operator meninjau secara manual |

### 4.2 Modul Kerja — do-nots compliance

| Terlarang | Ganti / framing aman |
|-----------|----------------------|
| agen tenaga kerja resmi | papan informasi lowongan mitra |
| LPK penyalur | (jangan klaim LPK; Nexus bukan lembaga pelatihan/penyalur) |
| PPTKS / P3RT / job portal berizin Kemnaker | bukan lembaga penempatan resmi |
| dijamin kerja / pasti diterima / 100% placement | kirim minat; keputusan ada pada pemberi kerja |
| fee daftar / biaya penempatan dari pencari kerja / uang jaminan kerja | **dilarang di UI** — fee pencari kerja = off |
| penempatan luar negeri / PMI / Jepang tanpa izin P3MI jelas | jangan framing PMI di MVP |

**Aman:** “Lowongan diposting mitra jaringan. Perekrutan dilakukan pemberi kerja sesuai aturan. PNC Nexus bukan lembaga penempatan resmi.”

### 4.3 Modul Komoditi — do-nots compliance

| Terlarang | Ganti / framing aman |
|-----------|----------------------|
| HET / HPP / SPHP / harga dijamin pemerintah / harga resmi Bapanas | harga **indikatif · penawaran mitra** |
| operasi pasar resmi | (jangan sebut) |
| stok nasional terjamin | volume penawaran mitra (apa adanya) |
| bersertifikat resmi / lolos BPOM / SNI tanpa bukti diverifikasi | tampilkan dokumen mitra apa adanya atau jangan klaim |
| angka harga sebagai data resmi lembaga tanpa sumber+waktu | larang; atau label sumber resmi + timestamp |
| iming-iming investasi / spekulasi komoditi | koneksi dagang antar mitra saja |

**Aman:** “Penawaran mitra (bukan harga resmi pemerintah). Verifikasi legalitas & dokumen tanggung jawab para pihak. Nexus memfasilitasi koneksi; kontrak jual-beli antar pihak.”

### 4.4 Modul Pemerintahan — do-nots compliance

| Terlarang | Ganti / framing aman |
|-----------|----------------------|
| UI/logo menyerupai LPSE / SPSE / e-katalog / INAPROC | visual netral PNC Nexus |
| terdaftar LPSE / langsung ikut lelang di Nexus / pengganti SPSE | info + dampingan internal |
| jamin menang tender / paket insider tender | disclaimer §6 + “tidak ada jaminan” |
| minta username/password SPSE | **dilarang** |
| upload dokumen pengadaan seolah proses resmi | **dilarang** — proses lelang hanya di sistem pemerintah |

**Aman:** “Informasi peluang & tautan ke portal resmi INAPROC/SPSE. Persiapan kapasitas mitra — proses lelang hanya di sistem pemerintah. CTA: Buka di INAPROC (eksternal).”

**Logo / visual:** jangan pakai lambang negara, logo LPSE/SPSE, atau layout yang meniru portal pengadaan resmi.

## 5. Disclaimer — kapan wajib

1. **Setiap view** modul `/pemerintahan` — banner penuh (§6.1 brief), tidak bisa di-dismiss permanen di MVP.  
2. **Saat minta dampingan** — checkbox wajib (§6.3 brief).  
3. **Footer app** (disarankan) — satu baris independensi platform.  
4. **Modul Kerja** — helper/footnote: bukan lembaga penempatan resmi; tidak ada fee pencari kerja.  
5. **Modul Komoditi** — label harga = penawaran mitra; bukan HET/HPP.  
6. **Marketing / landing** — bila menyebut pemerintahan, sertakan konteks “bukan portal resmi”.

Teks kanonik: `PRODUCT_BRIEF_MVP.md` §6 + `UX_COPY_DECK.md`.

- [ ] CTA sesuai peran & status verifikasi  
- [ ] Empty/error state membantu, tidak menyalahkan
