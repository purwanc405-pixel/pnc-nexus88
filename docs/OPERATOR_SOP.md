# SOP Operator — PNC Nexus MVP

**Tujuan:** penyaluran mitra cepat, patuh compliance, tanpa overclaim.

## Akun
- Operator: `ops@pnc.nexus` / seed password di README
- Admin: `admin@pnc.nexus` (approve status mitra, KPI, CSV)

## Rutinitas harian (15–30 menit)
1. **Mitra menunggu** (`/mitra`) — admin approve/tolak/tangguhkan; operator siapkan catatan kelengkapan.
2. **Inbox kerja** — cek aplikasi baru di detail peluang; update status bila ada proses internal.
3. **Komoditi** — pantau minat “tertarik”; hubungi pihak via WA di luar app (MVP tidak ada chat).
4. **Pemerintahan** — pantau permintaan dampingan; **jangan** minta password SPSE / upload tender ke Nexus.
5. **Pipeline** — pindahkan kartu: Baru → Ditinjau → Dihubungi → Tersalurkan / Tidak cocok.

## SLA internal (usulan, bisa diubah owner)
| Item | Target |
|------|--------|
| Review mitra baru | 1–3 hari kerja |
| Balas minat kerja | 2 hari kerja |
| Follow-up dampingan pemerintahan | 2 hari kerja |

## Patuh compliance (wajib)
- Kerja = papan lowongan mitra; **tidak** jamin placement; **tidak** pungut fee pencari kerja.
- Komoditi = penawaran mitra; **tidak** sebut HET/HPP/harga pemerintah.
- Pemerintahan = info + dampingan; lelang hanya di INAPROC/SPSE resmi (link eksternal).

## Eskalasi ke Admin / Owner
- Klaim berizin (Job Portal/PPTKS) di materi publik
- Fee penempatan, escrow, atau branding mirip lembaga
- Sengketa mitra / dugaan penipuan
